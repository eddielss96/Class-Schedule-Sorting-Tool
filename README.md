# 📅 課表編排器

國小・國中・高中 全年級課表編排工具。純前端靜態網站，不需伺服器，可直接架設在 **GitHub Pages**。

## 功能特色

- **自動排課**：一鍵為全校產生課表，自動滿足所有硬性條件；排不進去時會列出原因
- **手動微調**：拖拉課程方塊移動或交換位置，衝突即時以紅框與清單標示；可 🔒 鎖定課格（自動排課不變動）
- **排課條件**
  - 同一教師同一時段不會有兩堂課，並可設定教師「不排課時段」（兼行政、進修、特定日不到校）
  - 每班每科可設定「每週節數」與「連堂組數」（連續兩節）
  - 科目可設定「指定時段限制」（例如體育不排第一節）
  - 專科教室（音樂、電腦、實驗室…）同一時段只允許一個班使用
  - 班級可設定「不上課時段」（例如國小低年級下午沒課）
- **時段結構完全自訂**：每週 5～7 天、每天 1～14 節、節次名稱可自訂
- **三種檢視**：班級課表、教師課表、全校總覽，皆可列印
- **資料保存**：自動儲存於瀏覽器（localStorage），並支援 JSON 匯出／匯入備份

## 使用流程

1. **基本設定**：每週上課天數、每天節數（可先按「載入範例資料」試用）
2. **科目／教師／專科教室／班級**：建立基本資料，設定教師不排課時段、班級不上課時段
3. **授課設定**：指定每班每科的任課教師、每週節數、連堂、教室與時段限制
4. **課表編排**：按「⚡ 自動排課」，再以拖拉微調；「➕ 補排缺課」只補空缺不動現有課表

## 架設到 GitHub Pages

1. 進入 GitHub repo 的 **Settings → Pages**
2. **Source** 選擇 `Deploy from a branch`
3. **Branch** 選擇要發佈的分支（例如 `main`）、資料夾選 `/ (root)`，按 **Save**
4. 約一分鐘後，網站會出現在 `https://<你的帳號>.github.io/<repo 名稱>/`

不需要任何建置步驟，也沒有相依套件。

## 本機使用

直接用瀏覽器開啟 `index.html` 即可，或啟動任一靜態伺服器：

```bash
python3 -m http.server 8000
# 瀏覽 http://localhost:8000
```

## 技術說明

- 純 HTML / CSS / JavaScript，無框架、無建置流程
- 自動排課採 **MRV（最少候選優先）隨機化回溯搜尋**，多次重啟；無完整解時以貪婪法取得最佳可行結果並回報缺排
- 實測：24 班、45 位教師、每週 792 節的高中規模，約 4 秒內排完且零衝突

## 資料備份提醒

資料儲存在瀏覽器的 localStorage，**清除瀏覽器資料會一併清除課表**。請定期於「基本設定 → 資料管理」匯出 JSON 備份；換電腦時匯入即可延續編輯。
